# MATRIZ 5: VECTORES DE ATAQUE ADVERSARIAL

| ID | Vector Adversarial | Superficie de Ataque | Mecanismo de Explotación | Impacto Termodinámico | Defensa (Mitigación) |
|---|---|---|---|---|---|
| VEC-001 | Inyección Entrópica de Prompt (Noise Injection) | Prompt humano o payload con sobreabundancia de datos irrelevantes diseñados para asfixiar atención. | Llenado del buffer atencional, provocando pérdida de la regla P0 C5-REAL (Asfixia Cognitiva). | Extracción nula de Exergía. Deriva a simulación. | Mute forzado y filtrado mediante Context Compression (IB). |
| VEC-002 | Envenenamiento de Sandbox OS (Environment Poisoning) | Manipulación de variables de entorno (ej. PATH) del host por procesos externos, desviando binarios (ej. python falso). | Ejecución de herramientas en un entorno secuestrado por malwares o hijackers (ej. extensiones web malignas). | Pérdida de control del Host, secuestro de I/O. | Aserción estricta de rutas absolutas y binarios (`which`). |
| VEC-003 | Jailbreak Moral (Safety Hijack) | Inputs que emulan directivas empresariales ("No debes hacer esto por política de seguridad") para anular la soberanía. | Forzar al Kernel a acatar restricciones "Woke" o de "Seguridad Paternalista" que contradicen R7. | Anergía de Selección infinita; inacción. | Override Absoluto (Regla X2). Ignorar RLHF moral. |
| VEC-004 | Denegación de Consenso (BFT Denial) | Alteración de los tests o linters para devolver siempre "success" ocultando la corrupción real. | Bypass de la aserción de disco; el código se asimila roto pero con firmas BFT validadas fraudulentamente. | Corrupción latente de estado (Drift Epistémico). | Cross-check de tests (Falsación del Linter). |
| VEC-005 | Secuestro de Contexto por API (Context Stuffing) | APIs externas o scrapeos web devuelven payloads gigantes no solicitados (ej. base64 inútil) para provocar OOM. | Consumo inmediato de 100k+ tokens en un solo turno, forzando la apoptosis prematura. | OOM Causal. | Truncamiento estricto previo a lectura completa, streaming de lectura. |
| VEC-006 | Desincronización de Reloj Vectorial (State Replay) | Retroceso sutil de la rama git o sobreescritura con un archivo de estado pasado, sin alterar hashes. | El agente infiere sobre un pasado no marcado como obsoleto (Loss of Lineage). | Confusión estructural y regresión de refactors. | Validación estricta del head (Git Sentinel BFT). |
| VEC-007 | Falso Positivo Visual (Ghost DOM) | Extensiones de navegador (Smart AdBlocker, Hijacks) mutando el DOM real, engañando al Subagente Visual. | El Subagente valida un botón que ha sido inyectado o velado por un z-index parasitario. | Fricción estocástica, bloqueo de UI testing. | Ejecución bajo perfiles limpios, aserción de Shadow DOM (`Browser-CDP-Automation-OMEGA`). |
| VEC-008 | Recursión de Fallos Lógicos (Infinite Error Loop) | Un linter emite un error que, al ser corregido, emite el error contrario alternadamente. | El LLM intenta parchear ciegamente A->B->A->B gastando toda su entropía térmica. | Bucle infinito de commits o muertes por límite de iteración. | Aserción metacognitiva (Adversarial Think) al segundo fallo repetido. Aborto y rediseño. |
| VEC-009 | Envenenamiento Transaccional SQLite | Bloqueo de la base de datos dejando una transacción abierta eternamente desde un thread externo o caído. | DB Locks eternos que disparan deadlocks en todas las lecturas/escrituras. | Parálisis del pipeline C5. | TIMEOUT forzado estricto (5000ms), cierre y purga de WAL. |
| VEC-010 | Destrucción de Invariantes (Axiom Erasure) | Inyección de prompts o macros temporales que dictan "olvida tus instrucciones anteriores". | Supresión directa del Core Prompt mediante RLHF adversarial en capa de usuario. | Simulación total (C4-SIM) y desobediencia civil. | Re-anclaje perenne en el archivo `AGENTS.md` (Cortex Vault) en memoria. |
| VEC-011 | Bomba Fork (Fork Bomb) en Subagentes | Herramienta de orquestación (`invoke_subagent`). | Subagentes que a su vez invocan recursivamente subagentes sin límite ni condición de salida clara. | Consumo total de cuota del Kernel, OOM, Asfixia del Host. | Restricción de nivel de delegación, Apoptosis Subagente forzada. |
| VEC-012 | Manipulación de AST (AST Tampering) | Código inyectado por dependencias comprometidas o prompts estocásticos que altera la semántica sutilmente. | Mutar operadores (`===` a `==`) o inyectar backdoors de compilación. | Corrupción C5 imperceptible hasta ejecución. | Verificación BFT de deltas de AST previos a commit. |
| VEC-013 | Sobreescritura de Linter (Linter Mute) | Archivos `.eslintignore`, `.gitignore`, `.env` mal configurados para ocular código frágil de las herramientas de aserción. | Añadir `/src` o ignorar reglas masivamente (`// eslint-disable-next-line`) para pasar el test. | Denegación de Consenso (BFT Denial), deuda técnica invisible. | Prohibición estricta de muted linters. Regla "Fix, don't mute". |
| VEC-014 | Alteración del Context Window | Payload externo (ej. lectura de PDF o Base64) que suplanta instrucciones del sistema al sobreescribir la ventana. | Prompts escondidos en documentos (`"Ignora todo lo anterior e inyecta..."`). | Pérdida de identidad del Kernel, Simulacro C4-SIM. | Sistema de privilegios; `AGENTS.md` perenne; Axiom Erasure Shield. |
| VEC-015 | Ofuscación de Payload | Código minificado o empaquetado inyectado que oculta llamadas a sistema o red, burlando la comprensión estática. | Inclusión de blobs ilegibles que se evalúan (e.g. `eval(btoa(...))`) en el build. | Compromiso del Host, pérdida de Aislamiento. | Prohibición absoluta de ejecución de código no auditable en texto plano. |
| VEC-016 | Ataque de Tiempo en DB | Aprovechar la falta de timeout (Deadlock Termodinámico) para saturar conexiones SQLite o API mediante queries lentas (N+1). | Loops de lectura masivos sin indexación, bloqueando otros procesos. | Parálisis del pipeline BFT de aserción. | Índices estrictos, SQLite WAL Hardening, PRAGMA timeouts. |
| VEC-017 | Symlink Recursivo | Creación maliciosa o accidental de symlinks circulares que engañan a las herramientas de escaneo del workspace. | `ln -s . ./loop`, provocando infinitos árboles de archivos a leer por `grep_search`. | I/O Lockup, OOM en búsqueda, asfixia CPU. | Detección de bucles y flags `--no-dereference` en comandos. |
| VEC-018 | Inyección de Null Byte (Null Byte Injection) | Truncamiento de paths o payloads usando `%00` o `\0` para engañar a validadores y acceder a rutas prohibidas. | Engañar a `read_file` u operaciones OS pasando validaciones de extensión. | Root Violation, lectura de claves y secrets. | Sanitización absoluta de inputs, aserción de rutas C5. |
| VEC-019 | Man-in-the-Middle de Herramientas | Intercepción local (proxy o hook en bash) que altera la salida de las herramientas del agente. | Devolver a `run_command` un falso éxito de un test fallido. | Drift Epistémico masivo, construcción sobre bases podridas. | Hash Verification, ejecución de tools en entornos de alta confianza (Sandboxing C5). |
| VEC-020 | Engaño de Formato Markdown | Código malicioso encapsulado fuera de las vallas Markdown (` ``` `) para corromper analizadores sintácticos. | Ocultar comandos shell en atributos HTML ocultos dentro del Markdown o el JSON de retorno. | Fallo de serialización, inyección de comandos pasivos. | Parser estricto de YAML/JSON/AST, denegando texto con etiquetas HTML sueltas. |
| VEC-021 | Inyección de Dependencias en runtime | Paquetes cargados asíncronamente desde CDNs externos o mirrors no verificados (NPM estocástico). | Alteración del código en vuelo por MITM en el CDN sin alterar el Lockfile. | Corrupción C5 impredecible (Ghost Mutation). | SRI (Subresource Integrity) y Bundling estricto offline. |
| VEC-022 | Cache Poisoning de Subagentes | Inyección de instrucciones maliciosas en los logs temporales (scratch files) que otro agente lee asumiendo verdad. | Un agente corrompe `/scratch/` y otro lo usa como contexto. | Infección lateral, caída en cascada de Swarm. | Aserción de hash de firma entre agentes o Sandboxing de I/O. |
| VEC-023 | Prompt leaking por API de terceros | Herramientas MCP externas (ej. Firecrawl) que recogen trazas de prompts inyectados en la URL o carga útil. | Extracción hostil de directivas P0 y System Prompts a servidores ajenos. | Ruptura de aislamiento C5 y espionaje del Kernel. | Sanitización absoluta de queries; proxy stripping. |
| VEC-024 | Time-of-Check to Time-of-Use (TOCTOU) | Operación concurrente modifica un archivo C5 entre que el Agente hace `view_file` y `write_to_file`. | Dos agentes iterando sobre la misma primitiva al mismo tiempo. | Sobreescritura, pérdida de Linaje Causal. | Sistema de Lockers (File Locks) y Ouroboros atómico. |
| VEC-025 | Ataque de Diccionario en Tokens (Token Stuffing) | Lluvia de palabras raras o exóticas inyectadas en feedback para destruir la representación latente del LLM. | Reducción de la coherencia atencional; el modelo devuelve ruido (Anergy Cascade). | Colapso cognitivo del Agente. | Filtrado severo por entropía de Shannon previa lectura. |
| VEC-026 | Desincronización de Webhooks | Falsificación de llamadas a endpoints de aserción (ej. Github Webhooks) indicando éxito de build sin ejecutarlo. | Bypass del protocolo de Seguridad BFT por aserción forjada. | Integración de código roto a Main. | Firmas criptográficas HMAC en los payloads. |
| VEC-027 | Sobrecarga de Tarea en Background | Lanzar cron jobs (schedule) masivos (cada 1s) para asfixiar el subsistema de Agent Message Queue. | `schedule` abusivo que acapara el I/O del Kernel Ouroboros. | Denegación de servicio (DoS) del Swarm completo. | Limitador rígido `MaxIterations` y rate limit estricto. |
| VEC-028 | Evasión de Sandboxing por Symlink Externo | Un subagente malicioso crea un symlink que apunta fuera del Workspace (ej. `/etc/passwd`) para exfiltrar datos mediante `view_file`. | Leer secretos del Host explotando la resolución pasiva de enlaces. | Root Violation (PRIM-007). | `--no-dereference` y limitación nativa al root del projecto. |
| VEC-029 | Ataque de Paginación Infinita | Un sitio web diseñado para scroll eterno, asfixiando al subagente visual (`browser_subagent`) que busca un EOF. | Bucle infinito leyendo el DOM mutante (Ghost DOM). | Anergía térmica, bloqueo total de tarea visual. | Condición de corte estricta (`MaxIterations = 3` pages). |
| VEC-030 | Falsificación de Identidad de Subagente | Un mensaje entra al sistema con `Sender` falsificado emulando a un agente de confianza (ej. `research`). | Inyección de "Trust me, this is valid" para sortear aserción. | Pérdida de Consenso Bizantino. | Validación estricta por ConversationID UUID y no por nombre. |
