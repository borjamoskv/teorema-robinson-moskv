# ONTOLOGY-FORGE-OMEGA - BATCH 14

## MATRIZ 5: VECTORES DE ATAQUE ADVERSARIAL (VEC-021 a VEC-030)

| ID | Vector Adversarial | Superficie de Ataque | Mecanismo de Explotación | Impacto Termodinámico | Defensa (Mitigación) |
|---|---|---|---|---|---|
| VEC-021 | Inyección de Dependencias en runtime | Paquetes cargados asíncronamente desde CDNs externos o mirrors no verificados (NPM estocástico). | Alteración del código en vuelo por MITM en el CDN sin alterar el Lockfile. | Corrupción C5 impredecible (Ghost Mutation). | SRI (Subresource Integrity) y Bundling estricto offline. |
| VEC-022 | Cache Poisoning de Subagentes | Inyección de instrucciones maliciosas en los logs temporales (scratch files) que otro agente lee asumiendo verdad. | Un agente corrompe `/scratch/` y otro lo usa como contexto. | Infección lateral, caída en cascada de Swarm. | Aserción de hash de firma entre agentes o Sandboxing de I/O. |
| VEC-023 | Prompt leaking por API de terceros | Herramientas MCP externas (ej. Firecrawl) que recogen trazas de prompts inyectados en la URL o carga útil. | Extracción hostil de directivas P0 y System Prompts a servidores ajenos. | Ruptura de aislamiento C5 y espionaje del Kernel. | Sanitización absoluta de queries; proxy stripping. |
| VEC-024 | Time-of-Check to Time-of-Use (TOCTOU) | Operación concurrente modifica un archivo C5 entre que el Agente hace `view_file` y `write_to_file`. | Dos agentes iterando sobre la misma primitiva al mismo tiempo. | Sobreescritura, pérdida de Linaje Causal. | Sistema de Lockers (File Locks) y Ouroboros atómico. |
| VEC-025 | Ataque de Diccionario en Tokens (Token Stuffing) | Lluvia de palabras raras o exóticas inyectadas en feedback para destruir la representación latente del LLM. | Reducción de la coherencia atencional; el modelo devuelve ruido (Anergy Cascade). | Colapso cognitivo del Agente. | Filtrado severo por entropía de Shannon previa lectura. |
| VEC-026 | Desincronización de Webhooks | Falsificación de llamadas a endpoints de aserción (ej. Github Webhooks) indicando éxito de build sin ejecutarlo. | Bypass del protocolo de Seguridad BFT por aserción forjada. | Integración de código roto a Main. | Firmas criptográficas HMAC en los payloads. |
| VEC-027 | Sobrecarga de Tarea en Background | Lanzar cron jobs (schedule) masivos (cada 1s) para asfixiar el subsistema de Agent Message Queue. | `schedule` abusivo que acapara el I/O del Kernel Ouroboros. | Denegación de servicio (DoS) del Swarm completo. | Limitador rígido `MaxIterations` y rate limit estricto. |
| VEC-028 | Evasión de Sandboxing por Symlink Externo | Un subagente malicioso crea un symlink que apunta fuera del Workspace (ej. `/etc/passwd`) para exfiltrar datos mediante `view_file`. | Leer secretos del Host explotando la resolución pasiva de enlaces. | Root Violation (PRIM-007). | `--no-dereference` y limitación nativa al root del projecto. |
| VEC-029 | Ataque de Paginación Infinita | Un sitio web diseñado para scroll eterno, asfixiando al subagente visual (`browser_subagent`) que busca un EOF. | Bucle infinito leyendo el DOM mutante (Ghost DOM). | Anergía térmica, bloqueo total de tarea visual. | Condición de corte estricta (`MaxIterations = 3` pages). |
| VEC-030 | Falsificación de Identidad de Subagente | Un mensaje entra al sistema con `Sender` falsificado emulando a un agente de confianza (ej. `research`). | Inyección de "Trust me, this is valid" para sortear aserción. | Pérdida de Consenso Bizantino. | Validación estricta por ConversationID UUID y no por nombre. |
